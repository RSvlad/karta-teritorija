# Територије

## Деплој (GitHub Pages)

Workflow `.github/workflows/deploy.yml` на сваки push на `main` покреће `typecheck`, `test` и `vite build`, па објављује `dist/` на GitHub Pages. Pull request-ови пролазе исте провере, али се не објављују. Падање типова или тестова прекида деплој.

Посебан посао `quality` гради апликацију од демо података (никад од Sheet-а) и покреће Е2Е тестове (Playwright: претрага, WCAG AA, мете од 44 px, одзив < 200 ms на успореном процесору) и Lighthouse CI (брзина и приступачност ≥ 90, `lighthouserc.json`). Деплој чека и тај посао. Локално: `npm run build` без `GOOGLE_SERVICE_ACCOUNT`/`SHEETS_CITIES`, једном `npx playwright install chromium`, па `npm run test:e2e` и `npm run lighthouse`.

Генерисани JSON (`public/data/`) је у `.gitignore` и иде директно у артефакт за Pages; никада се не комитује.

### Једнократно подешавање

1. **Settings → Pages → Source: GitHub Actions.**
2. (Опционо) прилагођени домен: **Settings → Secrets and variables → Actions → Variables**, додати `CUSTOM_DOMAIN` (нпр. `primer.example`). Workflow тада уписује `CNAME` у `dist/`.
3. DNS код провајдера: `A` записи на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (за поддомен: `CNAME` на `RSvlad.github.io`).
4. Ако користите Cloudflare, подесите запис на **DNS only** док GitHub не изда сертификат; затим у **Settings → Pages** укључите **Enforce HTTPS**.

## Инсталација и рад без мреже (PWA)

`vite-plugin-pwa` у билду прави манифест и service worker (`dist/sw.js`); у `npm run dev` је искључен. Љуска апликације (укључујући мапу) се кешира при првом отварању, а `data/*.json` и `data/*.geojson` при првом учитавању: са мрежом се увек узима свежа датотека, а без мреже (или ако мрежа не одговори за 4 с) последња сачувана. Зато се нови подаци појављују при следећем отварању са интернетом, а град који никад није отворен на уређају није доступан без мреже. Плочице мапе које су већ виђене остају доступне.

Иконе су у `public/icons/` и праве се са `node scripts/make-icons.mjs` (без зависности).

## Подаци из Google Sheet-а

`npm run build` (преко `prebuild`) извршава `data-pipeline/build-data.mjs`: чита приватни Sheet преко Sheets API-ја и пише `public/data/cities.json` и `public/data/<град>.json` у облику `CityData` (`src/resolver/types.ts`). Нема нових зависности. Ако је иједан податак неисправан, билд пада са списком грешака (лист, ред, разлог) и ништа се не објављује.

### Подешавање

1. У Google Cloud-у направите service account, укључите **Google Sheets API** и **Google Drive API** (потребан само за датум последње измене Sheet-а, на ком почива упозорење о застарелим подацима; без њега билд упозори и користи датум билда) и преузмите кључ (JSON).
2. Поделите сваки Sheet са `client_email` из кључа (само читање).
3. **Settings → Secrets and variables → Actions → Secrets**:
   - `GOOGLE_SERVICE_ACCOUNT` – цео садржај JSON кључа;
   - `SHEETS_CITIES` – JSON низ, нпр. `[{"id":"novi-sad","name":"Нови Сад","sheetId":"<ИД из адресе Sheet-а>"}]` (опционо и `reportEmail`). `id` је облика `novi-sad`.

На `main` и ручном покретању деплој **захтева** ова два secret-а и никада не користи демо податке. Pull request-и без secret-а (нпр. из форка) користе демо податке само да би провере прошле.

### Шаблон Sheet-а

Први ред сваког листа је заглавље (редослед колона је слободан; велика/мала слова се не разликују).

**Територије** – обавезне колоне `ид`, `назив`, `боја`, `задужен`; опционо `заменик`, `напомена`.

| ид | назив | боја | задужен | заменик |
|----|-------|------|---------|---------|
| 14 | Либерти | #d9692b | Петар П. | Мира М. |

**Правила** – обавезне колоне `улица`, `територија` (ид из листа „Територије“); опционо `насеље`, `од`, `до`, `паритет`, `задужен`, `напомена`. Празно `од`/`до` значи отворен крај, празан `паритет` значи „сви“.

| улица | насеље | од | до | паритет | територија | задужен |
|-------|--------|----|----|---------|------------|---------|
| Футошка | Нови Сад |  | 15 | сви | 14 | Петар П. |
| Футошка | Нови Сад | 15 |  | непарни | 14 | Мира М. |
| Футошка | Нови Сад | 16 |  | парни | 15 |  |

Падајуће листе (**Подаци → Валидација података**): `паритет` = `сви, парни, непарни`; `територија` = опсег `ид` колоне листа „Територије“; `боја` = унос текста облика `#rrggbb`.

Проверава се: непозната територија, `од > до`, нецелобројне границе, непознат паритет, поновљен ид територије, боја која није `#rrggbb`, и улица истог назива у више насеља без наведеног насеља. Ид улице се прави од назива (и насеља само када се назив понавља), па не зависи од редоследа редова.

**Тачке** (опционо) – престонице и остале битне тачке; обавезне колоне `назив`, `територија` (ид), `адреса`; опционо `врста` (`престоница`, `сабирна` или `остало`; празно = `остало`), `напомена`.

| назив | територија | врста | адреса | напомена |
|-------|------------|-------|--------|----------|
| Сала Либерти | 14 | престоница | Футошка 1, Нови Сад |  |
| Сабирна тачка | 14 | сабирна | Јеврејска 3, Нови Сад | Недељом у 9:30 |

Свака територија мора имати **тачно једну** престоницу (када лист постоји, иначе билд пада). **У тачке не уносите приватне кућне адресе** – само јавна места (сале, паркинге, тргове). Без листа „Тачке“ билд ради, али картице немају престоницу и исписује се упозорење.

**Обим** (опционо) – улице које ограничавају територије; колоне `територија` (ид), `улица`; опционо `насеље`, `од`, `до` (укрснице: обе или ниједна). Билд из њега и из координата престоница црта границе територија (види „Цртање територија“ доле). Без листа „Обим“ мапа нема границе и пише „Мапа за овај град још није доступна“.

Поље `updated` је датум последње измене Sheet-а.

### Геокодирање тачака

Билд пише `data-pipeline/work/<град>/places-input.json` (у .gitignore). `data-pipeline/geocode.py` за сваку адресу прво тражи OSM адресну тачку (`addr:street` + `addr:housenumber` у граду), а тек ако је нема пита Nominatim (највише 1 захтев/с, како прописује његова политика). Резултат је `data-pipeline/cache/<град>/geocode-cache.json` и **комитује се**, па обичан билд никада не позива геокодер.

```
python data-pipeline/geocode.py --city novi-sad             # само адресе којих још нема у кешу
python data-pipeline/geocode.py --city novi-sad --refresh   # све адресе поново
```

Адреса је облика `<улица> <број>[, <насеље>]`. Адреса која одговара више удаљених OSM тачака се не погађа него се пријављује као двосмислена (додајте насеље). Неуспеле адресе се не кеширају, налазе се у `work/<град>/geocode-report.json` и приказују у извештају (`report.py`): престоница без координата је критична грешка (она покреће цртање), остале тачке су упозорење. Тачка без координата и даље ради на картици: навигација користи текст адресе.

### Индекс улица из OSM-а

Град је у `data-pipeline/cities.yml` (кључ = ид града, исти као у `SHEETS_CITIES`). `data-pipeline/streets.py` преузима именоване улице из OSM-а (OSMnx), додељује им насеље и пише `data-pipeline/cache/<град>/streets.json`. Тај фајл су јавни OSM подаци и **комитује се**, па обичан билд никада не позива OSM сервисе; освежава се намерно:

```
pip install -r data-pipeline/requirements.txt
python data-pipeline/streets.py --city novi-sad --refresh
```

Ако кеш постоји, `npm run build` га спаја са Sheet-ом: улице из OSM-а без правила постају претраживе и приказују се као „недодељене“, а улице из Sheet-а без пара у OSM-у исписују се као упозорење (не прекидају билд). Називи се пореде без обзира на писмо и величину слова; једно насеље на обе стране мора бити једнако, а празно насеље се слаже са било којим. Ид улица из Sheet-а се овим не мења. Без кеша билд ради као раније и исписује упозорење.

**Град без Sheet-а.** Град из `cities.yml` који има `cache/<град>/streets.json`, а није у `SHEETS_CITIES`, ипак се гради: улице из OSM-а су претраживе, град се појављује у избору „Град“, свака улица је „недодељена“, а мапа и „Где сам ја?“ се не приказују док град нема територије. Чим се град дода у `SHEETS_CITIES`, користе се подаци из Sheet-а. `npm run dev` ово ради и са демо подацима (`scripts/seed-demo-data.mjs`).

### Цртање територија

**Подразумевано се границе цртају само из листа „Правила“** – ништа више у Sheet-у није потребно (ни „Тачке“, ни „Обим“, ни геокодирање). `build-data.mjs` за сваку улицу која има правила прави ред `{улица, насеље, територије}` и `data-pipeline/territories.py` дели уличну мрежу на блокове:

1. Улица чија правила воде у **једну** територију припада њој; блок припада територији чије улице чине највећи део његове ивице.
2. Улица подељена између територија (парни/непарни, опсези бројева) је **граница** и ништа не додељује.
3. Блокови око означених (улице без правила) попуњавају се до 3 блока дубоко, у територију са којом деле највише ивице. Пруге, реке/канали и граница града су зидови; блокови већи од 1,5 km² (шума, њиве) се никад не боје.

Резултат је тачнији што је више улица додељено. Скрипта пише шта није сигурно: улице из Правила којих нема у OSM мрежи (проверите писање), територије без иједног блока, блокове без превласти и блокове без територије.

Старији начин (**престонице + лист „Обим“**) и даље ради, али само ако град има и лист „Обим“ и геокодиране престонице; иначе се користи горе описани. Опис тог начина:

`data-pipeline/territories.py` (Shapely/GeoPandas) дели уличну мрежу на блокове, а улице из листа „Обим“, пруге, реке/канале и границу града користи као баријере. Свака територија расте од своје престонице преко суседних блокова без прелажења баријере; територија је унија блокова. Улице које леже унутар територије (даље од њене границе) постају `internal` и наслеђују подразумеваног задуженог.

```
python data-pipeline/territories.py --city novi-sad --refresh   # мрежа из OSM-а → cache/<град>/network.json (комитује се)
python data-pipeline/territories.py --city novi-sad             # цртање
```

Улаз је `data-pipeline/work/<град>/territories-input.json` (у .gitignore): `territories` са `id` и `capital` (`lat`/`lng`, из #10) и `scope` са редовима листа „Обим“ (`territory`, `street`, `settlement`, опционо `from`/`to` = укрснице). Ако су наведене укрснице, баријера је само део улице између њих (обе или ниједна; свака страна булевара се сече посебно). Непозната улица или укрсница прекида цртање са читком поруком.

Излаз: `public/data/<град>.territories.geojson` (полигони) и `data-pipeline/work/<град>/territories.json` (`internal` улице и дијагностика: блокови које деле две територије, блокови без територије, територије без престонице или које додирују границу града). Свака територија се шири независно, па отворен обим даје „спорне“ блокове уместо да их тихо добије прва територија.

Ручна граница: `data-pipeline/overrides/<град>/<ид територије>.geojson` (полигон) замењује аутоматску; блокови унутар ње нису доступни другим територијама.

Билд (`build-data.mjs`) чита лист „Обим“, пише `territories-input.json` (престонице узима из `geocode-cache.json`) и на крају позива `territories.py`, па границе иду у деплој. Да би цртање радило потребно је да су комитовани `cache/<град>/network.json` и `cache/<град>/geocode-cache.json`; без њих (или без листа „Обим“) билд само исписује упозорење и мапа нема границе. Грешка у обиму (нпр. непозната улица) прекида билд. CI за то инсталира Python зависности (`pip install -r data-pipeline/requirements.txt`). `report.py` и попуњавање `internal` билд и даље не позива (остатак #9).

### Локални развој

Без `GOOGLE_SERVICE_ACCOUNT`/`SHEETS_CITIES` `npm run dev` и `npm run build` користе измишљене податке из `fixtures/` (`scripts/seed-demo-data.mjs`). Да локално проверите прави Sheet, поставите обе променљиве окружења пре `npm run build`.
